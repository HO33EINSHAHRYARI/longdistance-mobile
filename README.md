# 💜 اپلیکیشن نیتیو لانگ‌دیستنس (LongDistance Native Mobile)

اپلیکیشن ۱۰۰٪ نیتیو اندروید و iOS برای شبکه اجتماعی لانگ‌دیستنس، توسعه‌یافته با فریم‌ورک قدرتمند **Flutter** و اتصال مستقیم به سرور و دیتابیس `longdistance.ir`.

---

## ✨ ویژگی‌های برجسته:
* **رابط کاربری نیتیو ۶۰/۱۲۰ هرتز:** رندر مستقیم با موتور گرافیکی سیستم‌عامل، انیمیشن‌های روان و فاقد هرگونه لگ وب‌ویو.
* **فید سوایپ‌پذیر چندگانه (Swipeable Tabs):**
  * 🕒 «تازه‌ها» (Latest)
  * 👥 «دوستانم» (Following)
  * 🔥 «داغ‌ترین‌ها» (Hot 24)
  * 🔖 «ذخیره‌ها» (Saved)
* **سپر امنیتی و ضد کاربر مزاحم (Social Shield):**
  * مسدودسازی آنی دوطرفه (دکمه بلاک در منوی سه‌نقطه و کنار نظرات).
  * حذف فوری و انیمیشنی تمام پست‌ها و نظرات فرد مزاحم از دید کاربر.
  * سیستم گزارش تخلف با ذکر دلیل متنی به مدیریت.
* **لایک پیشرفته با انیمیشن Pop و هپتیک فیدبک:** انیمیشن فنری قلب هنگام پسندیدن.
* **کش هوشمند تصاویر (Offline Cache):** تصاویر لودشده در حافظه کش گوشی ذخیره می‌شوند تا بدون مصرف مجدد اینترنت باز شوند.
* **صفحه پروفایل با کاور کیهانی و انیمیشن شهاب‌سنگ:** نمایش فالوور، فالوینگ، پست‌ها و دکمه‌های فالو/آنفالو/بلاک.
* **پایپ‌لاین بیلد ابری در گیت‌هاب (GitHub Actions):** ساخت خودکار APK و AAB استاندارد بازار و مایکت در کمتر از ۲ دقیقه بدون نیاز به نصب هیچ ابزاری روی کامپیوتر.

---

## 🚀 نحوه اجرا و بیلد:

### روش ۱: بیلد ابری رایگان با GitHub Actions (پیشنهادی)
1. این پوشه را در یک ریپازیتوری گیت‌هاب قرار دهید.
2. گیت‌هاب به صورت خودکار فایل `.github/workflows/build_apk.yml` را اجرا کرده و فایل‌های `app-release.apk` و `app-release.aab` را مستقیماً برای دانلود به شما تحویل می‌دهد!

### روش ۲: اجرای محلی
```bash
flutter pub get
flutter run
flutter build apk --release
```
